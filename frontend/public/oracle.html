Positional averages — next drawing

For each match above, take the drawing that followed it, sort its numbers low to high, then average straight down the columns — the average 1st (lowest) number, 2nd number, and so on, in the drawing that came next. If the selected drawing's own next drawing is already on record, each tile shows it in teal and the delta from the average — i.e. how far this estimate actually landed from what really happened. Otherwise (the drawing hasn't had a follow-up yet) it falls back to the all-history baseline average instead. Either way, draws are independent — a handful of points off is typical noise, not a real miss or a real signal.
